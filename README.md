# Mahiru-music-bot
Step by step tutorial:
1. You need to create an app on https://discord.com/developers/home
2. Fill out all api, token,... in file .evn with yours;
       Discord token: From the app you created;
       Channel id: Copy one channel id on your server (Bot will send online notify on this channel);
       gemini api key: Go to https://aistudio.google.com/api-keys crate one and copy it;
3. Run the code
   That's it
   Enjoy:3
